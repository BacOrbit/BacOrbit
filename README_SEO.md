# تحسينات السيو (SEO) - BacOrbit

## ما تم تنفيذه (بدون أي تغيير في التصميم أو الهيكل الظاهر للصفحات):

1. **Meta description + keywords** لكل صفحة (25 صفحة) بمحتوى عربي مخصص لكل مادة/شعبة.
2. **Canonical URLs** لمنع مشاكل المحتوى المكرر.
3. **Open Graph + Twitter Card** لتحسين شكل الروابط عند مشاركتها في فيسبوك/واتساب/تويتر.
4. **JSON-LD (بيانات منظمة - Schema.org)**:
   - الصفحة الرئيسية: EducationalOrganization
   - كل صفحة: BreadcrumbList (مسار تنقل واضح لغوغل)
   - صفحات الشعب والمواضيع: CollectionPage
   - صفحات الدروس: LearningResource
   - صفحة اللعبة: Quiz
5. **تحسين وسوم <title>** لتكون أكثر وصفاً وغنى بالكلمات المفتاحية دون المبالغة.
6. **إصلاح alt الفارغ** في صور الدروس (كانت alt="" في كل صفحات L_*.html) وتعويضها بنص وصفي عربي (مهم جداً لبحث الصور في غوغل ولذوي الإعاقة البصرية).
7. **robots.txt** يسمح بالفهرسة الكاملة ويشير لخريطة الموقع.
8. **sitemap.xml** يضم كل الصفحات الـ 25 مع أولوية وتكرار تحديث مناسبين.

## ⚠️ أشياء عليك القيام بها يدوياً:

1. **صورة og:image**: أضفت مساراً افتراضياً `assets/og-cover.png` (1200×630px) في وسوم Open Graph/Twitter، لكن الصورة غير موجودة فعلياً — يجب عليك رفع صورة بهذا الاسم في مجلد `assets/` وإلا فلن تظهر معاينة عند مشاركة الروابط.
2. **ملف 1_info.html**: كان فارغاً (0 بايت) في نسخة المشروع التي تم تزويدي بها، فأعدت بناءه بالمحتوى المعروف من محادثاتنا السابقة (بطاقات "قريباً") + تحسينات السيو. تأكد من أنه مطابق للنسخة الفعلية لديك.
3. **رابط support.html و forum.html**: لاحظت أن top-bar في كل الصفحات يشير إلى `support.html` و`forum.html`، بينما الرابط الفعلي للمنتدى هو `chat.html`. هذا موجود مسبقاً في الكود الأصلي ولم أغيّره (خارج نطاق طلب السيو)، لكنه قد يسبب صفحات 404 تضر بالسيو - يستحسن تفقّده.
4. بعد الرفع، سجّل الموقع وخريطة sitemap.xml في **Google Search Console** لتسريع الفهرسة.
